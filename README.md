# LETEANE INDUSTRIES

Create a modern, clean, and highly professional corporate landing page for a South African technology and data engineering startup named "Letane Industries". 

The website must look like a high-end tech agency website. Use a sleek, minimalist color palette consisting of dark charcoal grays, deep slate blues, crisp white, and a single vibrant accent color like electric indigo or teal to signal data science and engineering innovation.

Structure the page with the following distinct sections:

1. HERO SECTION: A bold, clear headline: "Engineering the Data Pipelines of Tomorrow." Include a subtitle: "Letane Industries builds automated data aggregation systems, custom APIs, and intelligent data architecture for African enterprises and platforms." Add a primary call-to-action button that says "View Our Solutions".

2. FEATURED PROJECT SHOWCASE (The UJ Aggregator): Create a modern portfolio section highlighting our flagship proof-of-concept project: "The Johannesburg Campus Connect". Describe it as an automated, multi-source data pipeline that scrapes, cleans, and centralises fragmented university and social media event data for students in real-time. Show a mock layout or placeholder for a data dashboard or searchable events table.

3. OUR SERVICES: Use a clean 3-column or grid layout outlining our primary commercial capabilities:

   - Data Ingestion & Web Scraping (Automated ETL pipelines, custom wrappers, and proxy-backed data extraction).

   - Relational Database Architecture (Scalable SQL/PostgreSQL storage, indexing, and data warehousing).

   - API Deployment & Integration (Fast, secure RESTful APIs built with FastAPI to serve clean data to front-end apps).

4. ABOUT THE COMPANY: A brief section explaining that Letane Industries is a registered South African technology umbrella firm focused on turning raw, unstructured web data into structured, monetisable business intelligence assets.

5. FOOTER: Include professional standard links, placeholder text for a "Privacy Policy & Data Scraping Compliance", and a copyright note: "© 2026 Letane Industries (Pty) Ltd. All rights reserved."

Ensure the overall design relies on sharp typography, subtle grid dividers, ample whitespace, and avoids cartoonish graphics or generic stock images. Keep it corporate, credible, and technical.
